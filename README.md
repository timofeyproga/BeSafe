# BeSafe

A peer-to-peer messaging application built with Java.

## Overview

BeSafe is an experimental desktop messaging application
focused on direct peer-to-peer communication, cryptographic
identity and secure communication.

## Technologies

- Java 21
- JavaFX
- Maven
- TCP networking
- Ed25519
- X25519
- HKDF-SHA256
- AES-256-GCM

## Current Development Status

BeSafe is currently under active development.

Implemented components include:
- User identity generation
- Identity persistence
- TCP peer connections
- Binary communication protocol
- Cryptographic handshake prototype
- X25519 key exchange
- HKDF-SHA256 key derivation
- AES-GCM encryption and authentication tests

## Disclaimer

This project is experimental and is not ready for
production use or sensitive communications.
